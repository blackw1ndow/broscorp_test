# Лісовий архів — Telegram-бот

Бот запам'ятовує документи з порадами для життя в лісі (PDF, DOCX, TXT) і відповідає на питання звірів, завжди вказуючи, з якого документа взято пораду.

- Вимоги, з'ясовані із замовником, і ухвалені рішення: [docs/requirements.md](docs/requirements.md)
- Архітектура: [docs/architecture.md](docs/architecture.md)

## Запуск

```bash
cp .env.example .env   # вписати TELEGRAM_BOT_TOKEN і GROQ_API_KEY
docker compose up --build
```

При першому старті бот індексує 78 документів архіву (зокрема OCR сканів) — це займає кілька хвилин; далі архів уже в БД і старт миттєвий.

## Що вміє бот

- **Питання** — будь-який текст. Рукавичку звір називає в самому питанні («Скільки внесок під дубом?»). Якщо порада залежить від рукавички, а її не названо, бот спершу перепитує.
- **Документ** — файл PDF, DOCX або TXT до 20 МБ. Підпис до файла — це опис (для якого він місця). Уперше бот питає справжнє ім'я автора. Новіша версія того самого документа для того самого місця замінює стару.
- **Джерела** — під кожною відповіддю: документ, його місце і хто й коли його надіслав (або «Лісовий архів»).

| Команда | Що робить |
|---------|-----------|
| `/start`, `/help` | Привітання й довідка |
| `/docs` | Усі документи, які знає бот, за місцями |
| `/my_docs` | Власні документи з кнопками видалення |
| `/name <ім'я>` | Змінити ім'я, яке показується в джерелах |

## Тести
