# Вимоги до бота «Лісовий архів»

Джерело: переписка з Мишкою-шкряботушкою (19–22.10.2026) + тека «Лісовий архів» на Google Диску.

## 1. Підтверджені вимоги (від Мишки)

### Загальне
- R1. Документи — поради для життя в лісі, від великого путівника до однієї поради. Формати: PDF, Word, TXT. Фото документів не надсилають.
- R2. Тільки особисті повідомлення боту, не групові чати.
- R3. Файл — це документ, бот його запам'ятовує. Звичайний текст — питання.
- R4. Усі звірі рівні, адмінів немає.
- R5. Бот відповідає українською.
- R6. Стандартні документи з теки «Лісовий архів» бот знає одразу після запуску — їх ніхто окремо не надсилає.

### Місце дії поради (scope)
- R7. Кожна порада має місце дії: **весь ліс** → **частина лісу** (хвойний, листяний, біля річки) → **одна рукавичка**.
- R8. Звір сам вказує рукавичку в питанні («які гриби біля сосон?», «скільки внесок під дубом?»). Заздалегідь питати, хто де живе, не треба.
- R9. Порада для однієї рукавички іншим рукавичкам не підходить. Особисто тому звірові, що надіслав, документ не обмежуємо.
- R10. Пріоритет: конкретніша порада важливіша — рукавичка > частина лісу > весь ліс.
- R10a. Якщо порада залежить від рукавички, а її не вказано, бот **спершу перепитує**, про яку рукавичку йдеться. Загальною чи частковою порадою наперед не відповідає.

### Версії документів
- R11. Новіший варіант **того самого документа для того самого місця** замінює старий; старий більше не діє.
- R12. Однакова назва файлу сама по собі ще не означає оновлення — мають збігатися документ і місце.

### Відповідь і джерело
- R13. Завжди називати саму пораду й документ, з якого її взято.
- R14. Для документа від звіра — ще хто (справжнє ім'я) і коли його надіслав.

### Отримання документа
- R15. Якщо звір надсилає документ уперше — бот питає його справжнє ім'я.
- R16. Якщо незрозуміло, для якого місця порада, — бот перепитує про місце.

- R15a. «Справжнє ім'я» — ім'я, за яким звірі впізнають автора документа (не обов'язково Telegram-нік).

### Карта лісу (рукавичка → частина лісу)
- R17. Частин лісу три: хвойний, листяний, біля річки. Нових не планується.
- R18. Бот сам звіряє рукавичку з картою і бере поради для відповідної частини лісу:

| Рукавичка | Частина лісу |
|-----------|--------------|
| Під ялиною | хвойний |
| У соснах | хвойний |
| Біля мурашника | хвойний |
| Під дубом | листяний |
| У ліщині | листяний |
| Під вербою | листяний **і** біля річки |
| Біля бобрової греблі | біля річки |
| На узліссі | — (окреме місце: лише загальні поради + поради для самого узлісся) |

- R20. Один документ — один рівень і одне місце: весь ліс, одна частина лісу або одна рукавичка. Документ із розділами для різних місць треба розділити на окремі документи.
- R19. Для рукавички діють: поради для всього лісу + поради для її частин(и) лісу + поради для самої рукавички (пріоритет за R10).

### Структура
- **Весь ліс (7):** Календар сезонів, Карта лісу, Осінній путівник лісу, Правила толоки, Що робити при пожежі, Як кричати коли бачиш мисливців, Їстівне й отруйне.
- **Частини лісу (по 5 на кожну):**
  - хвойний: Грибний путівник, Небезпеки, Що їсти, Як не заблукати серед однакових сосен, Як утеплити рукавичку;
  - листяний: Грибний путівник, Небезпеки, Коли падають жолуді й горіхи, Що їсти, Як утеплити рукавичку;
  - біля річки: Броди і коли бобри відкривають греблю, Грибний путівник, Небезпеки, Що їсти, Як утеплити рукавичку.
- **Рукавички (7 типів × 8 рукавичок = 56):** Правила співжиття, Статут ОСМД, Небезпеки поруч, Стежки до сусідів, Чергування, Чим поживитись поруч, Членські внески.
- Кожен документ **у першому абзаці прямо каже, для кого він** («Ця порада для мешканців хвойного лісу», «Мешканці рукавички „Під дубом“…»). З цього бот визначає місце дії.

### ⚠️ Технічні знахідки
- **20 із 38 PDF — скани без текстового шару** (картинка з «брудним» фоном: плями, смуги). Звичайне витягування тексту повертає порожнечу → потрібне **OCR українською** (D22).
- Решта PDF — нормальний текстовий шар; DOCX і TXT — UTF-8, читаються без проблем.
