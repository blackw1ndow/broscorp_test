# Лісовий архів

Telegram-бот, який зберігає поради для життя в лісі й відповідає звірам на питання, спираючись лише на ці поради.

## Учасники

**Звір**:
Мешканець лісу, який пише боту в особисті повідомлення. Усі звірі рівні.
_Avoid_: користувач, адмін

**Справжнє ім'я**:
Ім'я, за яким інші звірі впізнають автора документа (напр. «Зайчик-побігайчик»), а не Telegram-нік.
_Avoid_: нік, username

## Місця

**Місце дії**:
Частина лісу, для якої чинна порада: весь ліс, частина лісу або одна рукавичка.
_Avoid_: scope, локація

**Весь ліс**:
Найзагальніше місце дії — порада для всіх.

**Частина лісу**:
Хвойний ліс, листяний ліс або берег річки. Рукавичка може належати до кількох частин або до жодної (напр. «На узліссі»).
_Avoid_: зона, район

**Рукавичка**:
Найконкретніше місце дії — одна оселя звірів (напр. «Під дубом»). Порада для рукавички важливіша за пораду частини лісу, а та — за пораду всього лісу.
_Avoid_: дім, будинок

## Документи

**Документ**:
Файл (PDF, DOCX, TXT) із порадами для одного місця дії. Будь-який файл від звіра — документ, будь-який текст без файла — питання.
_Avoid_: файл (коли йдеться про зміст)

**Порада**:
Окрема рекомендація з документа, яку бот називає у відповіді разом із джерелом.

**Тип документа**:
Назва документа без місця дії (напр. «Членські внески»). Тип і місце разом визначають, що це «той самий документ».

**Версія**:
Один із документів того самого типу для того самого місця. Чинна лише найновіша за датою надсилання; попередня оживає, якщо новішу видалено.
_Avoid_: копія, оновлення

**Архів**:
Стандартні документи, які бот знає від запуску. Їх не можна видалити, лише замінити новішою версією.
_Avoid_: Google Диск, тека

## Діалог

**Питання**:
Текст звіра без файла. Якщо порада залежить від рукавички, а її не названо, бот спершу перепитує.

**Очікування**:
Документ або питання, які бот прийняв, але не може обробити, доки звір не відповість на уточнення (справжнє ім'я, місце дії, рукавичка). Кілька документів можуть чекати одночасно, кожен незалежно; питання чекає лише одне — останнє.
_Avoid_: pending, незавершений запит
